# PDF Studio for Windows

Adobe Acrobat Pro の主要機能を備えた Windows 用 PDF エディタです（Electron + pdf.js + pdf-lib + tesseract.js）。
処理はすべて PC 内で行い、インターネット接続は不要です。

## インストール

- `PDF-Studio-Setup-1.5.19.exe` … インストーラー（このユーザーのみにインストールし、スタートメニュー・デスクトップにショートカットを作成）
- `PDF Studio（インストール不要版）` フォルダー … インストール不要版。中の `PDF Studio.exe` を実行（GitHub では `PDF-Studio-x.x.x-win.zip` を展開）

署名なしのアプリのため、初回起動時に「Windows によって PC が保護されました」と表示された場合は
「詳細情報」→「実行」を選んでください。

## 機能

| 分類 | 機能 |
|---|---|
| 表示 | 日本語 / 英語 / タイ語の切り替え、PDF と TIFF（複数ページ）を開く、タブで複数の文書を開く・並べて表示（左右・上下・最大 4 画面）、連続・見開き表示、ズーム（幅/全体/倍率、テンキーの ＋／－）、サムネイル、しおり、注釈一覧、全文検索 |
| 注釈 | ハイライト・下線・取り消し線、付箋、テキストボックス、手書き、矩形・楕円・直線・矢印、移動・リサイズ・色/太さ/不透明度/文字サイズの変更、元に戻す/やり直し |
| 編集 | 既存テキストの書き換え（白で覆って上書き）、画像の配置、リンク作成、トリミング |
| 署名・スタンプ | 手書き/文字入力の署名（保存して再利用）、承認・確認済・機密などのスタンプ、英語のスタンプ（APPROVED・CONFIDENTIAL など）、印鑑・日付印、カスタムスタンプ（文字・画像、日付が自動で入る動的スタンプ） |
| 測定 | 距離・周長・面積、縮尺（1:100 など）と単位、図面の寸法線からのキャリブレーション、頂点の調整 |
| ページ | ドラッグで並べ替え、回転、削除、複製、空白ページ挿入、ファイルから挿入（エクスプローラーからドロップ可）、抽出、分割 |
| 作成・結合 | 画像・Word (.docx)・テキスト・HTML から PDF 作成、複数ファイルの結合 |
| 一括処理 | 複数ファイルにまとめて OCR・透かし・ページ番号・ベイツ番号（通し番号）・フラット化・圧縮・プロパティ・パスワード保護を行い、PDF / Word / テキスト / 画像で保存 |
| フォーム | 既存フォームへの入力（日本語可）、テキスト欄・チェックボックス・ドロップダウンの作成 |
| 文書 | OCR（日本語・英語）、透かし、ヘッダー/フッター/ページ番号、ベイツ番号、墨消し（検索して一括マーク可）、注釈のフラット化、文書比較、プロパティ編集 |
| 保護 | パスワード暗号化（開くパスワード・権限パスワード・印刷/コピー/編集の制限）、解除、保護された PDF の編集 |
| 書き出し | Word (.docx)、テキスト、PNG/JPEG、ファイルサイズを縮小して保存、印刷 |

このアプリで付けた注釈は、保存後に再び開いても編集できます（他の PDF ビューアでも注釈として表示されます）。

## 自動アップデート（1.3.0 から）

- インストーラー版は、起動時と 6 時間ごとに新しい版を確認し、見つかると「ダウンロードしますか？」と尋ねます。ダウンロード後に「再起動して更新」を選ぶと更新されます（「次回の終了時に更新」も選べます）
- 「ヘルプ > アップデートを確認...」で手動でも確認できます
- 配信元: https://github.com/zr750104/pdf-studio/releases
- インストール不要版（zip）は自動更新されません。配布ページから最新版を入手してください
- 1.2.0 以前には更新機能がないため、1.3.0 だけは手動でインストールしてください

新しい版の公開（開発者向け）: `package.json` の version を上げ、`release-notes.md` を書いてから `scripts/release.sh` を実行します（事前に `gh auth login`）。

## 1.5.27 の変更点

- TIFF を開いて見ただけなら、閉じる・終了・自動更新のときに保存を確かめない（main.js needsAsk）。タブとタイトルの「●」も付けない。state.dirty は true のままなので「保存」はできる。編集したら確かめる

## 1.5.26 の変更点

- しおりの編集（doc.js readOutline / writeOutline / editOutline、panels.js outlineAction）。pdf.js の getOutline を { title, page, pos, url, items, closed, src } の木に読み、lib の元のしおりの辞書（src）を同じ形のときだけ対応づける。書き戻すときは元の辞書から構造（Title・Parent・Prev・Next・First・Last・Count）以外をそのまま写す（色・太字・動作・名前の移動先が残る）。閉じたしおりは Count を負に。古いしおりの辞書は消す（消した名前がファイルに残らない）。changeStructure の中で書くので取り消せる。URL のしおりは選ぶだけで、Ctrl + クリックで開く。元のしおりがあるのに pdf.js の読み取りと対応づけられないときは書き換えを断る（items.unmatched）。操作中の重ねての操作は受け付けない
- ページの大きさをそろえる（doc.js normalizePageSize、features.js normalizeSizeDialog）。見えている枠（CropBox。親から引き継いだものも）を基準に、ページごとに元の向きで、縦横比を保って中央に収める。元の中身は Form XObject（embedPage。その場で embed）にまとめて置く（中身の書き方や q/Q の釣り合いに左右されない）。用紙と表示範囲を新しい大きさにし、PDF の注釈（Rect・QuadPoints・L・Vertices・InkList）、しおり・リンク・/Dests・名前の木（/Names /Dests）の移動先の座標（共有している移動先は 1 回だけ）、このアプリの注釈（rect・points・strokes・quads・width・fontSize）を同じだけ動かす。測定の注釈は縮尺の係数を直して実寸を保つ。全面に 1 ビット画像 1 枚だけのページで縦横比が同じ（0.1% 以内）なら、画像の配置そのものを書き直してスキャン画像の速い表示の条件を保つ。/UserUnit のあるページは変えない。中身のない白紙のページは部品にまとめずに用紙と注釈だけを直す。スキャン画像のページで縦横比が違って速い表示から外れた数は知らせる。ページの素材（Resources）は部品だけを置く新しいものにする。タグ付き PDF の構造（MCID）や透明グループは部品の中に移るので、読み上げなどの対応が崩れることがある
- ログ（updater.log）にアプリの置き場所・開いたファイルの場所・インストール先・既定のアプリのコマンドを書かない（起動時は起動オプションとファイルの数だけ）。ユーザー名が入るため
- 自動テストで、しおり（入れ子・名前の移動先）・リンク・注釈・回転・文字のある文書を編集して保存し、開き直して確かめる

## 1.5.25 の変更点

- 「重ねて比較（図面）」（features.js compareOverlay・overlayPages、計算は renderer/overlay.js）。両方のページを同じ実寸の縮尺（200dpi、大きい方のページが 1200 万画素に収まるまで下げる）で描き、暗い画素を線とする。位置合わせは平行移動だけで、粗い画像（約 200 画素）で広く（大きい辺の 5%）探し、約 1000 画素・実寸で詰める（線の画素を最大 6 万点に間引いて重なりを数える）。相手の版の 2 画素以内に線があれば共通（にじみで縁が色づかない）。古い版だけ＝赤、新しい版だけ＝青、共通＝灰の PNG を古い版のページの大きさで新しい PDF に置き、左上に凡例と補正したずれ（mm）を書く。TIFF の相手は PDF に変換してから比べる。ページ数・大きさの違いは知らせる。1 ページずつ進み具合を出し、中止できる
- 傾き補正・余白の切り取りは入れていない（変形＋CropBox だとスキャン画像の速い表示〈scanpages.js〉の条件から外れて重くなる。画素を作り直すとファイルが大きくなり保存後は戻せない。どちらの方法にするかは今後決める）

## 1.5.24 の変更点

- TIFF を変換して開いただけ（setDirty(true, { converted: true })、state.convertedOnly）の間は、異常終了時の写しを作らない。本当に編集して setDirty(true) が呼ばれたら作る。main にも convertedOnly を送り、復元のときに同じ元ファイルの「変換しただけ」のタブは置き換える
- 前回の続きのファイル確認を、時間を区切った非同期の確認（existsSoon、1.5 秒）で行う。先にドライブ・共有フォルダーの単位（rootOf）で 1 回だけ確かめ、つながらない場所のファイルは確かめない（Node のスレッドを占有されて手元のファイルまで時間切れになるのを防ぐ）。つながらない（ドライブが見つからない・時間切れ）ファイルは前回の続きの記録に残し（deferredTabs、tries を数える）、3 回続けて開けなければ外す。ファイルだけがない（移動・削除）ときはすぐ外す。後回しのファイルを手で開いたら後回しの一覧から外す。起動処理は await し、失敗したら空のウィンドウを開く。起動の途中のファイル指定なしの二重起動は無視する
- タブは作った時点で開くファイルの場所（tab.path）を持つ（読み込み中に終了しても前回の続きから消えない・復元の重複判定と最近使ったファイルで見つかる）。開けなかったら外す。準備前のウィンドウは host.restoring を記録する。起動処理は try/finally で起動中の印を必ず外す
- 自動テストで、起動時と同じく新しいウィンドウに前回の続きを開く流れ、見つからないファイルだけのとき、つながらない場所、読み込み前の記録、復元で同じファイルのタブを置き換える流れを確かめる

## 1.5.23 の変更点

- 開く時間の記録：main の `open read`・`ready`、レンダラーの `open timing`（形式・大きさ・ページ数・時間。ファイル名は書かない）
- 設定ファイルは、読めない（ロック中など）ときは書かない（readSettingsStrict。ほかの設定を消さないように）。壊れていたら settings.json.bak に退避して作り直す。書くときは一時ファイルに書いてから置き換える

## 1.5.22 の変更点

- ウィンドウにドロップした画像・Word（.docx）・テキスト（.txt .md .csv .html .htm）を、1 ファイルずつ PDF にして開く（features.js の droppedKind / prepareDropped / openDropped）。先頭 4KB だけ読んで形式を見分け、対応するものだけ全部読む。テキストは拡張子も確かめる（文字だけの .json や .js までは PDF にしない）。ドロップでは場所が分からないことがあるので、変換は中身（bytes）から行う（main.js の convert-to-pdf は場所のほかに { bytes, name } も受ける）。処理中のドロップは捨てずに順に処理する。対応していないものは理由付きで知らせる
- インストール不要版：起動したときに `HKCU\Software\Classes\Applications\PDF Studio.exe\shell\open\command` を今の exe に書き直す（defaultapp.js の repairPortableOpenWith）。新しい版を別のフォルダーに展開すると、ダブルクリックで古い場所の exe を探して開かなくなっていたため。「プログラムから開く」で選ばれたことがない（登録がない）とき、登録先がインストール版のとき、前に書いた版（PDFStudioVersion。書いたときの exe の PDFStudioExe が今の登録と同じときだけ信用する）が今より新しくその exe があるときは書き直さない。native-reg で直接書く（外部プログラムは起動しない）。ログに場所は書かない。書いている途中でアプリが止められた（セキュリティソフトなど）ときに毎回繰り返さないよう、書く前に userData に `portable-openwith.pending` を作り、書き終えたら消す（残っていたら二度と試さない）
- 自動テスト（--selftest）はウィンドウを見えなくして裏で動かす（不透明度 1%・マウス素通り・フォーカスを奪わない・App Nap を止める・画面はフォーカスがあるものとして動かす）。見たいときは `PDFSTUDIO_TEST_VISIBLE=1`。180 秒進まなければ止まった場所を出して終わる。予定していない保存の確認は出さずに失敗として数える

## 1.5.21 の変更点

- 表示倍率の範囲を 8.33%〜6400%（PDF-XChange Editor と同じ）にした。大きく拡大しても、ページ全体の画像は画素数の上限内で描き、見えている部分だけを細かく描く（1.5.19 の仕組み）。全ページを並べた高さが画面の部品の上限（約 3,000 万ピクセル）を超えないよう、ページが多い文書では上限の倍率を下げる（viewer.js clampScale。ページの追加・並べ方の切り替え・ページの大きさが分かったときも applySizes で収め直す）。回転したスキャン画像のページは細かい画像を作らないため、大きく拡大するとぼやける
- 保存の確認に「今後は確認せず、次から同じ操作をする」を付けた。印を付けて保存・保存しないを選ぶと settings.json の savePrompt に覚える（キャンセルは覚えない）。「編集」メニューの「閉じるときの保存の確認」（毎回確かめる・確かめずに保存する・確かめずに保存しない）で変えられる。チェックボックスを受け取るため確認は非同期になり、確認の表示中はそのウィンドウのほかの閉じる操作を受け付けない。「確かめずに保存する」で保存できなかった（名前を付けて保存をキャンセル・書き込みの失敗）ときは、その回だけいつもの 3 択の確認を出す（main.js の save-close-failed）
- インストーラーで `Software\Classes\Applications\PDF Studio.exe` に FriendlyAppName（と SupportedTypes：.pdf .tif .tiff）を書き、MuiCache に残った古い表示名を消す（「プログラムから開く」に「Electron」と出ていたため）。アンインストールでは書いた値だけを消す

## 1.5.15 の変更点

- 複数ページの TIFF をさらに速く開く：G4（ファクス形式）の展開を pdf.js の CCITT デコーダに替え（UTIF.js の約 50 倍速、結果は同一）、ページを複数のワーカーで並行して展開。実機ログで 256 ページ約 10 分だったものが、計算上は数秒〜十数秒

## 1.1.0 の変更点（軽量化・不具合修正）

軽量化
- 表示中のページ付近だけを描画し、離れたページの画像・描画データは解放（300 ページの PDF を最後までスクロールしたときのページ画像のメモリ：約 1.2GB → 約 12MB）
- ズームは拡大縮小した画像をすぐ表示し、落ち着いてから描き直す（描画完了まで 1.5 秒 → 0.05 秒）
- サムネイルは本体の描画が空いているときに描き、遠くのものは解放
- 取り消し履歴は変更部分だけを保持し、PDF 本体のコピーには上限を設定
- 配布ファイルを整理（インストーラー 128MB → 97MB、同梱ファイル数 約 2,500 → 20）。OCR は画面側の Worker で実行

不具合修正
- 墨消しを適用して保存しても、差し替え前のページの中身（隠した文字）がファイル内に残っていた
- ページの並べ替え・削除を繰り返すとファイルが大きくなっていた
- マウスで文字を選択できず、ハイライト・下線・取り消し線・コピーが使えなかった
- ズームやウィンドウの大きさを変えたあと、ページが白紙のままになることがあった
- 選択ツールで何もない所をクリックしても注釈の選択が解除されなかった
- 作成者が編集・コピー・印刷を制限した PDF を保存すると制限が外れていた（今後は制限を守り、保存後も維持）
- 暗号化された PDF をページとして挿入すると壊れたページになっていた（パスワードを尋ねるように）
- 処理の途中で失敗したとき、文書が中途半端な状態で残ることがあった
- 墨消し範囲にかかるフォーム欄の入力値が残っていた
- 保存は一時ファイル経由で行い、書き込み中に失敗しても元のファイルを壊さないように
- ダイアログを Esc で閉じるとツールの選択まで解除されていた

## 開発

```bash
npm install
npm run vendor       # 実行に必要なライブラリを renderer/vendor にコピー
npm start            # 起動
npm test             # 自動テスト（electron . --selftest）
npm run perf         # 性能計測（electron . --perftest）
npm run dist         # Windows 用インストーラー / zip を dist/ に作成
```

この Mac で Windows 用を作るときは、`.tools/node`（Node.js）と `.tools/nsis`（NSIS）を置いて使っています（`.tools` はリポジトリに入れていません）。公開は `scripts/release.sh`。

## 制限事項

- 「テキスト編集」は元の文字を白で覆って新しい文字を重ねる方式です（段落の再流し込みは行いません）。
- 墨消しを適用したページは画像化されます（必要なら後から OCR を実行してください）。
- Word 書き出しはテキストのみで、レイアウト・画像は再現されません。
- しおりは閲覧のみ（編集不可）です。
