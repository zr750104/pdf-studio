## PDF Studio 1.5.21

- 表示倍率を 8.33%〜6400% にしました（これまでは 10%〜600%）。倍率の一覧に 400%・800%・1600%・2400%・3200%・6400% などを足しました。ページ数がとても多い文書では、上限が少し低くなることがあります
- 「変更内容を保存しますか？」に「今後は確認せず、次から同じ操作をする」を付けました。印を付けて「保存」か「保存しない」を選ぶと、次からは確かめずにその操作をします。「編集」メニューの「閉じるときの保存の確認」でいつでも戻せます
- エクスプローラーの「プログラムから開く」で、アプリ名が「Electron」と表示されることがあったのを「PDF Studio」と表示するようにしました（インストール版。反映にはサインインし直しが要ることがあります）

**インストール版**：`PDF-Studio-Setup-1.5.21.exe` をダウンロードし、PDF Studio を閉じてから実行してください。
**インストール不要版**：`PDF-Studio-1.5.21-win.zip` をダウンロードして展開し、中の `PDF Studio.exe` を起動してください。

---

- Zoom now ranges from 8.33% to 6400% (previously 10% to 600%), with more presets up to 6400%. Very long documents may have a slightly lower maximum.
- The "Save changes?" prompt has a "Don't ask again" option. If you tick it and choose Save or Don't Save, that action is used from then on. Change it any time in Edit > Save Prompt When Closing.
- "Open with" in File Explorer now shows "PDF Studio" instead of "Electron" (installer version; you may need to sign out and back in).
