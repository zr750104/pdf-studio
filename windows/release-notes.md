## PDF Studio 1.5.22

- 画像（PNG・JPEG・GIF・BMP・WebP）・Word（.docx）・テキスト（.txt・.md・.csv・.html）をウィンドウにドラッグ＆ドロップすると、PDF にして開くようにしました（これまでは何も起きませんでした）。対応していないファイルは、その旨をお知らせします
- インストール不要版：新しい版のフォルダーで起動すると、ファイルのダブルクリックで開くアプリの場所を新しい版に書き直すようにしました（古いフォルダーを消すと、ダブルクリックで開かなくなっていました）。インストール版が入っている場合は、インストール版のままにします

**インストール版**：`PDF-Studio-Setup-1.5.22.exe` をダウンロードし、PDF Studio を閉じてから実行してください。
**インストール不要版**：`PDF-Studio-1.5.22-win.zip` をダウンロードして展開し、中の `PDF Studio.exe` を起動してください。

---

- Drag and drop images (PNG, JPEG, GIF, BMP, WebP), Word (.docx) and text files (.txt, .md, .csv, .html) onto the window to open them as PDF (previously nothing happened). Unsupported files are reported.
- Portable version: when started from a new version's folder, it now updates the app that opens files on double-click (it stopped working after deleting the old folder). If the installer version is installed, it is left as is.
