## PDF Studio 1.5.30

- 「重ねて比較（図面）」の位置合わせを直しました。通り芯や格子のように同じ間隔で線が並ぶ図面で、線 1 本ぶんずれた位置に合わせてしまうことがありました
- 「重ねて比較（図面）」で、画層の組み合わせを使っている図面を、見えている線だけで比べるようにしました（隠れているはずの線が写ることがありました）
- 「重ねて比較（図面）」で、太い線の片側だけを使って位置を合わせてしまうことがあったのを直しました

**インストール版**：`PDF-Studio-Setup-1.5.30.exe` をダウンロードし、PDF Studio を閉じてから実行してください。
**インストール不要版**：`PDF-Studio-1.5.30-win.zip` をダウンロードして展開し、中の `PDF Studio.exe` を起動してください。

---

- Overlay Compare (Drawings) alignment is fixed. On drawings with evenly spaced lines, such as grids, it could align one line off.
- Overlay Compare (Drawings) now compares only the visible lines on drawings that use layer combinations (hidden lines could appear before).
- Overlay Compare (Drawings) no longer aligns using only one side of thick lines.

---

- แก้ไขการจัดตำแหน่งของ "เปรียบเทียบแบบซ้อนทับ (แบบแปลน)" ในแบบที่มีเส้นเรียงห่างเท่ากัน เช่น เส้นกริด อาจจัดตำแหน่งเหลื่อมไปหนึ่งเส้น
- "เปรียบเทียบแบบซ้อนทับ (แบบแปลน)" เปรียบเทียบเฉพาะเส้นที่มองเห็นในแบบที่ใช้การรวมเลเยอร์ (ก่อนหน้านี้เส้นที่ควรซ่อนอาจปรากฏ)
- "เปรียบเทียบแบบซ้อนทับ (แบบแปลน)" ไม่จัดตำแหน่งโดยใช้เพียงด้านเดียวของเส้นหนาอีกต่อไป
