## PDF Studio 1.5.32

- 距離の測定で表示された数値を、選択ツールのときしか動かせなかったのを直しました。手のひら（最初の道具）や測定ツールのままでも、数値をつかんで動かせます。保存して開き直した PDF でも動かせます

**インストール版**：`PDF-Studio-Setup-1.5.32.exe` をダウンロードし、PDF Studio を閉じてから実行してください。
**インストール不要版**：`PDF-Studio-1.5.32-win.zip` をダウンロードして展開し、中の `PDF Studio.exe` を起動してください。

---

- Fixed the Measure Distance value only being movable with the Select tool. You can now drag it with the Hand tool (the default) or the measure tools too, including in saved and reopened PDFs.

---

- แก้ไขให้ค่าที่แสดงในการวัดระยะทางย้ายได้เฉพาะเมื่อใช้เครื่องมือ "เลือก" ตอนนี้สามารถลากค่าได้แม้ใช้"เครื่องมือมือ" (เครื่องมือเริ่มต้น) หรือเครื่องมือวัด รวมถึงใน PDF ที่บันทึกแล้วเปิดใหม่
