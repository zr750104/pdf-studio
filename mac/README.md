# PDF Studio for Mac

Adobe Acrobat Pro の主要機能を備えた macOS 用 PDF エディタ（Swift / AppKit / PDFKit / Vision）。
すべて Mac の中で処理し、外部サービスは使いません（新しい版の確認だけ GitHub の配布ページを見ます）。
Windows 版（PDF Studio for Windows）と同じ機能を、Mac の部品で作っています。

## インストール

1. 配布ページ（https://github.com/zr750104/pdf-studio/releases）から `PDF-Studio-Mac-x.y.z.zip` をダウンロードして開く
2. 出てきた「PDF Studio」を「アプリケーション」フォルダーに入れる
3. 最初の起動だけ：開こうとして「開けません」と出たら、「システム設定 > プライバシーとセキュリティ」の下のほうにある「このまま開く」を押す（Apple の開発者署名がないため）

Apple シリコン（M1〜M4）の Mac、macOS 14 以降。新しい版が出ると起動時にお知らせします（ダウンロードページを開きます）。

## 2.1.0 の変更点

- TIFF を開いて見ただけなら、閉じるとき・終了するときに保存を確かめない（元の TIFF は残っている。編集したら確かめる）。PDFStudioDocument.makeNew の edited
- 文書の画面へのドロップ（DropOpen.swift）：PDF・TIFF は開く。画像・Word（.docx）・RTF・HTML・テキスト（.txt / .md / .csv、UTF-8 / UTF-16 / Shift_JIS）は 1 ファイルずつ PDF にして新しい文書で開く。開けないファイルは名前と理由を知らせる。サムネイルの欄へのドロップ（ページの挿入）はこれまでどおり
- しおり（OutlineEdit.swift）：上下の並べ替え・1 段下げる／上げるを追加。追加・削除・名前の変更も含めて元に戻せる（逆の操作だけを登録し、文書全体は書き出さない）。取り消しはしおりの位置（番号の並び）で覚え、削除したしおりは中身を値で控えて今の文書のページで作り直す。**PDFKit は読み込んだ文書のしおりの変更を保存に反映しない**（2.0.0 までの追加・削除・名前の変更も保存されていなかった）ため、しおりを変えた文書（Compositor.markOutlineEdited）は、ページを複製した新しい文書にしおりを作り直して保存する（スタンプと同じく /AcroForm とページラベルは失われるので、最初の編集で 1 度知らせる）
- 重ねて比較（図面）（Overlay.swift、「文書を比較…」の下）：Windows 版 overlay.js と同じ計算。200dpi（大きい方のページが 1200 万画素に収まるまで下げる）、平行移動のずれを 3 段で探し、相手の 2 画素以内の線は共通。古い版だけ＝赤、新しい版だけ＝青、共通＝灰で、古い版の大きさのページに凡例と補正したずれ（mm）を書く。TIFF は変換してから比べる。表示中の文書の写しを裏で描き、進み具合を出して中止できる
- ページの大きさをそろえる（PageSize.swift、「ページ」メニュー）：A3・A4・A5・B4・B5（JIS）・Letter・Legal・Tabloid。ページごとに縦横の向きは元のまま、縦横比を保って中央に収める（すべてのページ）。内容は CGPDFPage をベクターのまま描き直し、回転は残す。注釈（枠・線の端・手書き・ハイライトの四隅・線の太さ・文字の大きさ・画像スタンプ）、リンクとしおりの移動先も同じだけ動かす。測定は実寸が変わらないよう縮尺も直す。フォームの入力欄は位置だけ動かす
  - 既知の制限：描き直すので、レイヤー（OCG）とタグ付きの構造は消える。ポップアップ付きの注釈（付箋など）は、画面の数と位置は正しいが、PDFKit がページをまたいで注釈を移すと保存したファイルの中の /Popup・/Parent の結び付きが写しを指す（見た目は同じ。ほかのアプリで付箋の文を書き換えると食い違うことがある）。破線の間隔・多角形の頂点（/Vertices）・フォームの文字の大きさは変えない

## 2.0.0 の変更点

- 最初の言語を英語にし、日本語・英語・タイ語に対応（「PDF Studio > 言語 / Language」）
- TIFF（複数ページ）を開く。白黒の FAX 圧縮はそのまま PDF に入れるので、256 ページでも 1 秒かからない
- タブの文書を 1 つのウィンドウに並べて表示（左右・上下・最大 4 画面）。操作は枠の付いた画面に効く
- テンキーの ＋／－ で拡大・縮小。手のひらツールで払うと滑ってスクロール（上下の向きの不具合も修正）
- 縮小して横に 2 ページ以上入ると、ページを横に並べた一覧で表示
- 寸法の測定（距離・周長・面積）、縮尺（1:100 など・単位）、図面の寸法線からのキャリブレーション、頂点の調整
- スタンプの追加：英語のスタンプ、至急、自分で作る文字・画像のスタンプ（下段に日付・時刻・氏名を自動で入れる）
- 置いた画像・署名・スタンプを、保存して開き直しても動かせるようにした（ページに焼き込まない）
- プロパティパネルを、ツールバーの下の書式バーに変更（ツール・選択に合わせて必要な項目だけ）
- 一括処理（OCR・透かし・ページ番号・ベイツ番号・フラット化・圧縮・プロパティ・パスワード → PDF / Word / テキスト / 画像）
- 不具合の報告（ヘルプ メニュー。ユーザー名・ファイル名は伏せて GitHub の報告ページに下書き）
- 「ファイルサイズを縮小して保存」で逆に大きくなる不具合を修正（「標準」「強力」を選べる。小さくならなければ保存しない）

## ビルド

```bash
./build_app.sh            # PDF Studio.app をこのフォルダに作成
./build_app.sh --zip      # 配布用の PDF-Studio-Mac-<版>.zip も作る
./build_app.sh --install  # /Applications にもインストール
.build/release/PDFStudio --selftest <出力フォルダ>   # 自動テスト（PDFSTUDIO_LANG=ja|en|th で言語を指定）
python3 scripts/check_i18n.py                       # 訳の抜けを調べる
```

macOS 14 以上 / Xcode が必要です。

## 機能

| 分類 | 機能 |
|---|---|
| 表示 | 単一・連続・見開き・ブック表示、ズーム、サムネイル、しおり、注釈一覧、全文検索 |
| 注釈 | ハイライト・下線・取り消し線、付箋、テキストボックス、手書き、矩形・楕円・直線・矢印、移動/リサイズ/色・太さ・不透明度・フォント変更、取り消し/やり直し |
| 編集 | 既存テキストの書き換え（白塗り＋上書き）、画像の配置、リンク作成、トリミング |
| 署名・スタンプ | 手書き/文字の署名（保存して再利用）、承認・確認済・機密などのスタンプ、印鑑・日付印 |
| ページ | ドラッグで並べ替え、回転、削除、複製、空白ページ挿入、ファイルから挿入（Finder からドロップも可）、抽出、分割 |
| 作成・結合 | 画像・Word・RTF・テキスト・HTML から PDF 作成、複数ファイルの結合 |
| フォーム | テキストフィールド・チェックボックス・ドロップダウンの作成、フォーム入力 |
| 文書 | OCR（日本語対応、検索・コピー可能に）、透かし、ヘッダー/フッター/ページ番号、ベイツ番号、墨消し（検索して一括墨消しも可）、注釈のフラット化、文書比較、プロパティ編集 |
| 保護 | パスワード暗号化（開くパスワード・権限パスワード・印刷/コピー/編集の制限）、解除 |
| 書き出し | Word (.docx)、RTF、テキスト、PNG/JPEG、ファイルサイズを縮小して保存、印刷 |

## 制限事項

- 「既存テキストの編集」は元の行を白で覆って新しい文字を重ねる方式です（Acrobat のような段落の再流し込みはしません）。
- 墨消しを適用したページは画像化されます（必要なら後から OCR を実行）。
- フォームの欄やページラベル（i, ii などのページ番号の表記）がある PDF に画像・署名・スタンプを置いて保存すると、フォームの設定とページラベルが失われることがあります（PDFKit の制限。置くときに案内します）。
- Word 書き出しはテキストと書式のみで、レイアウトや画像は再現されません。
