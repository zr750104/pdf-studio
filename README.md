# PDF Studio

PDF・TIFF の閲覧と編集ができるアプリです。Windows 版と Mac 版があります。

- **ダウンロード:** [配布ページ（Releases）](https://github.com/zr750104/pdf-studio/releases)
  - Windows 版：`PDF-Studio-Setup-x.y.z.exe`（インストーラー）または `PDF-Studio-x.y.z-win.zip`（インストール不要版）
  - Mac 版（Apple シリコン）：`PDF-Studio-Mac-x.y.z.zip`
- インストール済みのアプリは、この配布ページから自動で更新を受け取ります。
